# AI 작사 · AI 작곡 프롬프트 스튜디오

성인 대상 AI 작사·작곡 수업용 프롬프트 작성 도우미 웹앱입니다.
API 키 없이, 단계별로 고르고 쓴 내용으로 프롬프트를 만들어 생성형 AI(Claude·ChatGPT·Gemini·뤼튼)와 AI 작곡 도구(Suno·Udio)에 붙여넣어 사용합니다.

## AI 작사 (6단계)
글 스타일 선택(일기·편지·시·수필·인생 회고 등 12종) → 주제·감정 → 질문에 답하며 내 이야기 쓰기 → 노래 설정(곡 길이 30초·1분·2분·정규곡) → 작사 변환 프롬프트 / 자동 뼈대 / 가사 편집·줄 수 확인·길이 맞추기 프롬프트 → 완성

| 곡 길이 | 가사 분량 | 구조 |
|---|---|---|
| 30초 | 6줄 이내 | [Verse] 2줄 → [Chorus] 4줄 → [End] |
| 1분 | 10줄 이내 | [Verse] 4줄 → [Chorus] 4줄 → [Outro] 2줄 → [End] |
| 2분 | 18줄 이내 | [Verse 1] 4 → [Chorus] 4 → [Verse 2] 4 → [Chorus] 4 → [Outro] 2 → [End] |
| 3분 이상 | 20~40줄 | 구조 템플릿 선택 |

## AI 작곡 (8단계)
장르(추천 40종 먼저 표시 · 전체 221종) → 분위기 → 템포·리듬 → 악기 → 보컬 → 시대·사운드 → 구조·추가 요청 → Suno용 스타일 프롬프트 완성(한국어 풀이 포함)

## 장르 샘플 듣기 (Suno)
장르 칩 옆 ▶ 버튼을 누르면 Suno로 만든 샘플이 화면 안 재생기로 열립니다.

1. 장르별 Suno 곡을 **공개(Public)** 로 만들고 공유 링크를 엑셀 '장르 목록' 시트의 'Suno 공유 링크' 칸에 붙여넣습니다.
2. `python tools/excel_to_samples.py "장르샘플_제작가이드_Suno링크.xlsx"` 를 실행하면 `samples.js` 가 다시 만들어집니다.
3. 다시 배포하면 링크가 있는 장르에 ▶ 버튼이 생깁니다.

## 실행
`index.html` 하나로 동작합니다. 브라우저로 열거나 정적 호스팅에 배포하세요. 입력 내용은 브라우저(localStorage)에만 저장됩니다.
